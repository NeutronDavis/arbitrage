       ABI matches Uniswap QuoterV2 quoteExactInputSingle signature and returns.

2. src/pricing/uniswap_v3.rs:
   - Added IUniswapV3Factory.feeAmountTickSpacing and IERC20.balanceOf bindings.
   - Extended V3Pool struct: { venue: Venue, fee: u32, address: Address, quoter: Address }.
   - Added discover_pancake_pools:
     * Reads enabled fee tiers dynamically from the factory (feeAmountTickSpacing > 0).
     * Checks pool existence via getPool.
     * Checks WETH balance via balanceOf(pool) and warns/skips any pool under 10 WETH.
   - Parameterized build_quote_call and quote functions with quoter: Address so
     Uniswap and PancakeSwap quote calls reuse the identical logic and calldata encoding.

3. src/strategy.rs:
   - Extended Venue enum:
     #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)]
     pub enum Venue {
         UniswapV3 { fee: u32 },
         PancakeV3 { fee: u32 },
         SushiV2,
     }
   - Implemented Display ("UniV3-{fee}", "Pancake-{fee}", "SushiV2") and FromStr.
   - Updated MarketState with liquidity lookups for all venue types and optional Sushi.
   - Updated process_block_batched to package all V3 pool reads (Uniswap + Pancake)
     and first leg quotes into Batch 1, and all second leg quotes across other venues
     into Batch 2, retaining exactly 2 Multicall3 aggregate3 calls per block.
   - Updated to_records to preserve canonical ordering and string-encoded reserves/liquidity.

4. src/config.rs:
   - Added `pub venues: Vec<Venue>` parsed from VENUES env var.
     Default: "UniV3-500,UniV3-3000,Pancake-100,Pancake-500".
     SushiV2 and UniV3-10000 remain fully supported in code but are off by default.
   - Changed default TRADE_SIZES_WETH to "0.05,0.1,0.25,0.5".

5. src/main.rs:
   - Dynamic pool discovery for all configured venues at startup.
   - Dry-run tables updated to display prices, depths, and spreads for all active venues.
   - Decimals sanity check compares prices against deepest available tier.
