1. OVERVIEW & OBJECTIVES
--------------------------------------------------------------------------------
Phase 2f expanded the read-only Arbitrum scanner to scan many WETH pairs across
Uniswap V3 and PancakeSwap V3, driven by a reviewed token allowlist to identify
pairs where cross-venue arbitrage spreads ever turn positive.

Key requirements & constraints strictly maintained:
- Read-only execution: no wallet, no transactions, no PRIVATE_KEY.
- Security constraints: no .env files created, edited, read, or deleted; no secrets
  or RPC URLs printed.
- Authoritative token verification: cited source for every token (Arbiscan token
  page), on-chain bytecode verification, symbol() check, and decimals() check.
  Any token failing on-chain checks is marked UNVERIFIED and excluded from scans.
- Strict Allowlist Enforcement: only entries with `reviewed = true` are evaluated by
  `--discover` and loaded by the scanner. Unreviewed tokens are printed and skipped.
- Target Token Edit (cbETH): Replaced with cited Coinbase Arbitrum One contract
  (0x1DEBd73E752bEaF79865Fd6446b0c970EaE7732f), retaining `reviewed = false`.
- Automated `--discover` engine: queries UniV3 & PancakeV3 factories across all
  enabled fee tiers, filters for WETH depth >= MIN_POOL_WETH (default 10 WETH),
  requires >= 2 distinct venue/tier combinations, measures single-leg price impact
  ladder at 0.05, 0.25, and 1.00 WETH, selects 3 trade sizes per market with impact
  <= 3 bps (capped at 5 WETH), writes `data/markets.json`, and prints summary tables.
- Market fallback: scanner loads from `data/markets.json`, filtering for reviewed tokens.
- Chunked Multicall3: splits batches into chunks (size 40) so eth_call payloads
  stay well within provider limits. Reports call counts and largest gas estimate.
- Reference ETH/USD pricing: JSONL logs include `est_gross_profit_usd` based on
  the block-pinned WETH/USDC UniV3-500 quote.
- Summarizer upgrades: configurable `--usd-min` (default 0.01), screening rows with
  spread > 0 and USD >= usd_min. Header explicitly documents fixed trade sizes.
- Persistence view: tracks longest run of consecutive sampled blocks with spread > 0,
  and with spread > -1 bps.
- Proxy audit: computes EIP-1967 beacon slot from spec (`keccak256("eip1967.proxy.beacon") - 1`),
  identifying beacon proxies and resolving implementation addresses.
- Bounded test execution: live run ended on its own (`timeout 180`) and logged
  to temporary output file `data/live_test_phase2f_fixes.jsonl`.
