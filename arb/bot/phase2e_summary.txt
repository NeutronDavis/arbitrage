1. OVERVIEW & OBJECTIVES
--------------------------------------------------------------------------------
Phase 2e generalized the read-only arbitrage logger from a single market
(WETH/USDC) to multiple concurrent markets:
  1. WETH/USDC (6 decimals)
  2. WETH/WBTC (8 decimals)
  3. WETH/USDT (6 decimals)

Key requirements & constraints strictly maintained:
- Read-only execution: no transactions, no wallet, no private keys.
- No .env files created, edited, read, or deleted; no secrets printed.
- Preserved exactly 2 Multicall3 aggregate3 RPC calls per processed block across ALL
  markets and venues combined (Batch 1: reads + 1st legs; Batch 2: 2nd legs).
- Zero RPC calls for SushiSwap V2 math (local constant-product formula).
- Bounded test execution using timeout and temporary output files.
- Accurate reporting of gross spreads: negative numbers explicitly indicate net losses;
  never labeled as good.
- Strict backwards compatibility: old JSONL rows without a `pair` field parse and
  summarize seamlessly as "WETH/USDC".

--------------------------------------------------------------------------------
2. CODE CHANGES & ARCHITECTURE
--------------------------------------------------------------------------------
1. src/constants.rs:
   - Added WBTC (0x2f2a2543B76A4166549F7aaB2e75Bef0aefC5B0f, 8 decimals)
     Source: Official Arbitrum Token List & Arbiscan token page
     On-chain verified: symbol()="WBTC", decimals()=8.
   - Added USDT (0xFd086bC7CD5C481DCC9C85ebE478A1C0b69FCbb9, 6 decimals)
     Source: Tether official transparency deployments & Arbiscan token page
     On-chain verified: symbol()="USDT", decimals()=6.

2. src/config.rs:
   - Introduced `MarketConfig`:
     * `symbol`: e.g. "USDC", "WBTC", "USDT"
     * `pair`: e.g. "WETH/USDC", "WETH/WBTC", "WETH/USDT"
     * `quote_token`: Address
     * `quote_decimals`: u8
     * `venues`: Vec<Venue>
     * `trade_sizes_weth`: Vec<f64>
   - Multi-market configuration via optional `MARKETS` env var (default: "USDC,WBTC,USDT"):
     * WETH/USDC: UniV3-500, Pancake-100, Pancake-500; sizes: [0.05, 0.1, 0.25, 0.5]
     * WETH/WBTC: UniV3-500, Pancake-100; sizes: [0.1, 0.5, 1.0, 2.0]
     * WETH/USDT: UniV3-500, Pancake-100, Pancake-500; sizes: [0.05, 0.1, 0.25]
   - Decision on `VENUES` and `TRADE_SIZES_WETH`: Retained as overrides specific to
     `WETH/USDC` to ensure full backwards compatibility with existing test scripts.

3. src/pricing/uniswap_v3.rs & src/pricing/mod.rs:
   - Extended `V3Pool` with `pair: String` and `quote_token: Address`.
   - Implemented `discover_market_pools`:
     * Queries `feeAmountTickSpacing > 0` on factory (UniV3 or PancakeV3).
     * Discovers pool address via `getPool(WETH, quote_token, fee)`.
     * Queries `balanceOf(pool)` on WETH and skips any pool with < 10 WETH with a warning.
   - Generalized `build_quote_call` to take `token_in` and `token_out` directly.
   - Updated `decode_quote_result` to return `Option<(U256, u64)>` (amount out, gas estimate).
   - Added `implied_quote_per_weth` helper for multi-decimal quote token rate calculations.

4. src/strategy.rs:
   - Generalized `FirstLeg` and `RoundTrip` with `pair`, `quote_token`, `quote_decimals`,
     and `mid_amount` (raw units of quote token).
   - Updated `OpportunityRecord`:
     * `pair`: String (defaults to "WETH/USDC" when deserializing old records).
     * `mid_amount`: String (raw quote units).
     * `usdc_mid`: String (filled for WETH/USDC rows, empty string for other pairs).
   - Updated `process_block_batched`:
     * Packages all pool reads, timestamp, and first-leg quotes for ALL markets into Batch 1.
     * Packages all cross-venue second-leg quotes for ALL markets into Batch 2.
     * Computes payload bytes for both batches and tracks `max_gas_estimate`.
     * Total RPC calls per processed block remains strictly 2.

5. src/summary.rs:
   - Grouping key updated to `(pair, venue_a, venue_b, direction, size_weth)`.
   - Legacy rows without `pair` automatically default to "WETH/USDC".
   - Unit tests added and passing: `test_summarize_multi_pair_and_legacy_rows`.

6. src/main.rs:
   - Startup discovery across all markets.
   - `--dry-run-once` snapshot displays per-market implied prices and confirms venue
     agreement within 10 bps.
   - Displays top gross spreads per market, explicitly labeling negative spreads as NET LOSS.
   - Logs Multicall3 call counts, payload sizes, and largest gas estimate per block.
